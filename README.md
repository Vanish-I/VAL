# VAL Launcher | Vanilla Authentic Life

### VAL (Vanilla Authentic Life) — проект модифицированной сборки RimWorld 1.7 (преимущественно, с возможностью работы на 1.6) и собственного лаунчера, ориентированный на более глубокий, сложный и аутентичный игровой опыт.

## Возможности лаунчера позволяют на данный момент:

• Создавать свои сборки с возможностью разделять их по тематикам;

• Отслеживать совместимость модов, основную информацию;

• Поддержка сторонних модификаций;

• Активировать и деактивировать модификации, а так-же сохранять их состояние.

## Будущие возможности лаунчера:

• Сортировать моды непосредственно перед заходом в игру

• Полноценно работать с игровыми сборками

• Изучать отчеты об ошибках 

• Возможность кастомизации под себя

• Реализация системы поддержки

• Расширенное взаимодействие с модификациями и дополнительные инструменты для работы с ними
